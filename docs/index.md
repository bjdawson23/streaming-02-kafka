## Custom Project

### Dataset

Tthe dataset used by the Kafka producer:

- The name of the dataset file is sales.csv.
- This dataset contains records of sales transactions
- Fields included in each record:  order_id,datetime,region_id,currency_code,product_id,unit_price,quantity,is_online,customer_id,is_new_customer,device_type,payment_method,referral_source,discount_code,customer_note
- This is the original sales dataset.

### Kafka Messages

The producer sends messages sent through Kafka.
It will count PayPal payments and reports that count at the end of the run.

Include:

- Updated send function to return both total sent and PayPal count
- Updated summary function to accept and log PayPal count

### Consumer Processing

The consumer receives and does these things with each message:

- The consumer receives from Kafka sales information from the sales.csv file in this case.
- The consumer received 20 message(s) from topic 'streaming-02-kafka-case'.
- It logs and prints each of the messages on screen and to a CSV file.
- It processes and filters the payment_method field looking for a count of PayPal usage.

### Experiments

- Phase 4: changed .env PRODUCER_MESSAGE_COUNT to 20.
- Phase 5 application:  Changed producer to log the number of PayPal payment_method transactions occured.
- I also changed the consumer to process the messages and log the number of records that used Paypal.

### Results

- 20 message(s) were sent to topic 'streaming-02-kafka-case'
- The total PayPal payment_method count was: 9

### Interpretation

The Kafka streaming workflow showed me:

- The number of messages and logging changed from the original example by modifying .env.
- In watching messages move through Kafka, I learned that it can process the data very efficiently.
- The logging and time to view messages can be modified to make seeing realtime messages easier.
- A stream like this could tell a business or organization what payment method is trending right now.
- I gained BI of aggregating how many PayPal transactions occured over a small time frame.
